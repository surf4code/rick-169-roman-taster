# CASTING (character designer)
Characters are FLAT 2.5D cutouts, never 3D geometry. Files: `CharacterSvg.tsx`, `CutoutCharacter.tsx` (+ character table).
For each character define: outfit (colours, collar, belt), hair/headwear, one distinguishing feature, skin tone, face block (eye gap/size, brow length, mouth). Use the measurements in the Bible section 1-2 (head circle, 2% outline, gold rim on lit side, tiny eyes/mouth, face block low).
Every character must be recognisable in silhouette and in 3 emotions. Keep one consistent look across all shots.
Output a character sheet still (`npx remotion still ...`) with every character in neutral + 2 emotions. QA checks it against the Bible.
