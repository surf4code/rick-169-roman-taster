# Structures: length templates and format shapes

Use when: outlining a video or deciding how long and in what shape it should be.

Pick **length** first, then **format**, then fill the beat cards. Word counts below
assume a spoken pace of roughly 140-160 words a minute. That is a planning
assumption: time the creator reading a paragraph aloud and adjust.

## Step 1: choose a length

| Goal | Spoken words (approx) | Body beats | Best for |
|---|---|---|---|
| 5-8 min | 700-1200 | 3 | One tight idea, one demo, one lesson |
| 10-15 min | 1500-2200 | 4-5 | A topic that needs context plus proof |
| 20-25 min | 3000-3800 | 6-8 in 3 acts | A deep dive, a story with turns |

Rule: the length is set by how many beats the promise truly needs. If a beat does
not move the promise forward, cut it. Do not stretch to hit a time.

## Template A: 5-8 minutes

```
0:00-0:30   Hook (one formula, scored)
0:30-1:00   Promise + why it matters to this viewer
1:00-5:30   Beat 1, Beat 2, Beat 3 (about 1.5 min each)
5:30-6:30   Payoff: close every open loop, one-line recap
6:30-7:00   One CTA, then end screen
```
Notes: one re-hook before beat 3. Keep the recap to one sentence.

## Template B: 10-15 minutes

```
0:00-0:45   Hook
0:45-2:00   Context: what you will cover and the one thing to remember
2:00-4:00   Beat 1 (foundation)
4:00-6:00   Beat 2
6:00-6:30   Midpoint re-hook: a surprise, or a reversal of what the viewer expected
6:30-9:00   Beat 3 and Beat 4 (the strongest material goes here, not last)
9:00-11:00  Beat 5 / climax: the answer, demo, or result
11:00-12:00 Payoff + recap
12:00-12:30 One CTA, end screen
```
Notes: place chapter breaks at beat boundaries (seo-chapters.md).

## Template C: 20-25 minutes (three acts)

```
0:00-1:00    Hook, promise, one open loop that pays off late
1:00-3:00    Context and stakes
ACT 1 (3:00-8:00)    2 beats: set the problem, first attempt or first fact
Re-hook at about 8:00
ACT 2 (8:00-16:00)   3-4 beats: complications, evidence, rising tension
Breather at about 12:00: a lighter beat, joke, or recap before the next climb
Re-hook at about 16:00
ACT 3 (16:00-21:00)  2 beats: the turn, the answer
21:00-23:00  Resolution: what it means for the viewer, loops closed
23:00-23:30  One CTA, end screen
```
Notes: write the ending first so every act points at it.

## Step 2: choose a format shape

### Story
Best for: a person, event, or experiment with a beginning and an end.
Skeleton: scene -> want -> obstacle -> attempt -> setback -> turn -> outcome -> lesson.
Trap: telling events in the order they happened instead of the order they matter.
Check: can you state the viewer's question in one line (what happens to X)?

### List
Best for: tips, tools, mistakes, ranked picks.
Skeleton: hook -> criteria (how items were chosen) -> items -> bonus or surprise -> verdict.
Trap: the weakest item first and the strongest last, with a sag in the middle.
Check: each item stands alone, has one example, and gets roughly equal time.
Tip: put a strong item first and the best second-to-last or last; never bury it.

### Explainer
Best for: "how does X work" or "why does X happen."
Skeleton: question -> simple wrong model -> reveal the flaw -> correct model -> worked example -> where it breaks.
Trap: starting with definitions instead of the puzzle.
Check: after each step, could a beginner restate it in one sentence?

### Essay
Best for: an opinion or argument with a point of view.
Skeleton: claim -> strongest counterargument -> your evidence -> concession -> refined claim -> what to do about it.
Trap: only presenting the side you agree with.
Check: would someone who disagrees say you described their view fairly?

### Documentary
Best for: investigations, histories, "what really happened."
Skeleton: mystery -> timeline -> key sources (named, dated) -> contradiction -> resolution or honest unknown -> impact.
Trap: stating unverified claims as fact. Every factual beat needs a source in the log (research.md).
Check: could a viewer find each source you cite?

## Beat card (fill one per beat)

```
Beat #:        Title (chapter-ready):
Purpose:       what this beat changes in the viewer's mind
Claim:         one sentence
Proof:         example, demo, source (tag [VERIFY] if unsure)
Visual:        what is on screen
Exit line:     the sentence that pulls into the next beat
Est. words / time:
```

## Pacing rules

- One idea per beat. If a beat needs "and also," split it.
- State the claim first, then support it.
- Strongest material belongs in the first half or at the climax, not buried.
- Put at least one visual or demo in every beat.
- Last beat ends with value, then the single CTA. Never end on a recap alone.

## Structure checklist

- [ ] Promise stated in one sentence and delivered by the end
- [ ] Length matches the number of beats (no padding, no rushing)
- [ ] Each beat has a purpose, claim, proof, visual, exit line
- [ ] A re-hook sits at the midpoint (10+ minute videos)
- [ ] Every open loop is closed before the CTA
- [ ] Format traps checked (see the format's "Trap" line)
- [ ] Word count roughly matches time goal
