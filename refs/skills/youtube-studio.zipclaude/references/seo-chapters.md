# SEO, description, chapters, tags

Use when: writing the description, chapter timestamps, tags, or choosing keywords.

SEO here means helping the right viewer find the video and understand it fast. It
is not stuffing. No tools or APIs are needed; everything below works from the
script and what the creator can see in the YouTube search box.

## 1. Find the keyword (no tools)

1. Write the viewer's problem in their words, not the creator's.
2. Type the first few words into YouTube search and note the autocomplete phrases.
3. Search the best phrase and look at the top results: what angle do they take? What is missing?
4. Read a few comments on related videos for the wording people actually use.
5. Pick one **main phrase** and two or three **close variants**.
6. If the phrase has no natural fit with the video's real content, change the phrase, not the video.

Do not state search volumes or competition numbers unless the user supplies them.

## 2. Where the keyword goes

| Place | How to use it |
|---|---|
| Title | Main phrase early and in natural language |
| Hook / first spoken lines | Say the phrase aloud once, naturally |
| Description, first lines | Restate the promise using the phrase |
| Chapter titles | Use descriptive words and variants, not "Part 2" |
| On-screen text and captions | Spell it correctly; check auto-captions for errors |
| File name and thumbnail alt text (if any) | Plain descriptive wording |

Say the phrase and its variants in the voiceover where they fit. Never force it.

## 3. Description layout

```
Line 1:  The promise, with the main phrase (what the viewer will get).
Line 2:  The one primary link or action (matches the video's single CTA).

2-4 sentences: what the video covers and for whom, in plain words.

CHAPTERS
0:00 [Opening]
0:45 [Chapter title]
...

RESOURCES
- [Link and what it is] (only items mentioned in the video)

SOURCES
- [Source log entries worth showing; titles and links the user supplied]

ABOUT THE CHANNEL
- One sentence on what the channel covers, plus where to follow.
```

Rules:
- Only the first lines show before "more" on most screens, so put the value there. Rule of thumb: about the first 100-150 characters; check on a phone.
- One primary link above the fold. Additional links go lower.
- No links or claims the video does not contain.
- Disclose sponsorships or affiliate links as the creator's rules and local law require; ask the user if unsure.
- Do not copy the script into the description.

## 4. Chapter timestamps

Format: `m:ss` or `h:mm:ss`, one per line, with a title.

Rules (verify current YouTube behavior before relying on edge cases):
- The first chapter must start at `0:00`.
- Provide at least three chapters, listed in ascending order.
- Keep each chapter at least about ten seconds long.
- Use the same format on every line (no mixing of styles).
- Titles: short, descriptive, keyword-aware, and written for a scanning viewer.
- Chapter boundaries should match the beat boundaries in the outline (structures.md).
- Timestamps in a draft are estimates; confirm against the final edit before publishing and mark `[CONFIRM AFTER EDIT]`.

Example layout (placeholders only):
```
0:00 Intro
0:40 [First beat title]
3:10 [Second beat title]
...
```

## 5. Tags

- Tags play a small role; a title, thumbnail, and description matter more.
- Use 5-10 relevant tags: the main phrase, close variants, common misspellings, and the topic.
- Include the series or channel name if one exists.
- Do not add unrelated popular terms.
- Never promise results from tags.

## 6. Hashtags (optional)

- Use zero to three relevant hashtags, placed in the description or title.
- A few clear ones are better than many; too many can be ignored. Verify the current limits.

## 7. Other discovery levers

- **Pinned comment:** the single CTA or a useful resource; one comment only.
- **Playlists:** add the video to a playlist that matches its topic.
- **End screen and cards:** point to one related video; plan 15-20 seconds in the edit.
- **Language/captions:** upload accurate captions when possible; fix the main phrase's spelling.
- **Related-video bridge:** mention the next video by its real topic in the last beat.

## SEO checklist

- [ ] One main phrase from real search behavior, not guessed volume
- [ ] Main phrase in title, early spoken lines, description line one
- [ ] Description leads with the promise and one primary link
- [ ] Chapters start at 0:00, are in order, at least three, descriptive
- [ ] Chapter timestamps flagged for confirmation after editing
- [ ] Tags relevant, not padded; hashtags minimal
- [ ] All links and claims in the description appear in the video
- [ ] No invented numbers or sources in the metadata
